## 🏛️ Architecture Highlights

### ⚡ Next.js 16 Cache Components
- Utilizes Next.js 16's `'use cache'`, `cacheTag()`, and `cacheLife()` primitives for instant page delivery.
- Custom CMS publishing pipeline automatically invokes `updateTag()` / `revalidateTag()` for instant cache invalidation without full rebuilds.

### 🛡️ Single-Database Better Auth Architecture
- Unified auth model powered by Better Auth using the native MongoDB adapter.
- Single-organization schema supporting strict role separation (`admin` / `client`) and project gating (`clientProjectIds`).
- Passkey support (`@better-auth/passkey`) and robust session handling without edge runtime fragility.

### 🧩 shadcn/ui on Base UI Primitives
- Zero Radix dependency — strictly aligned with the latest shadcn/ui standard over `@base-ui/react`.
- Accessible form layouts built with `FieldGroup`, `Field`, `FieldLabel`, and `InputGroup` patterns.
- Fully tokenized Brutalist-Editorial theme in `globals.css` with zero ad-hoc styling overrides.

### 🤖 Intelligent AI Agent Integration
- Built-in AI assistant leveraging the `@google/genai` SDK with `gemini-3.5-flash-lite`.
- Domain-grounded system knowledge base for interactive service pricing estimation, discovery scheduling, and client onboarding.

## 🚀 Getting Started

### Prerequisites
- **Node.js**: v20.x or higher
- **Package Manager**: `npm`, `pnpm`, or `bun`
- **Database**: MongoDB Atlas connection string

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/shammashassan/hakt-website.git
cd hakt-website
npm install
```

### 2. Environment Configuration
Create a `.env.local` file in the root directory:
```env
NEXT_PUBLIC_APP_URL="http://localhost:3000"

# MongoDB Database
MONGODB_URI="mongodb+srv://<user>:<password>@cluster.mongodb.net/hakt-website"

# Better Auth Configuration
BETTER_AUTH_SECRET="your-generated-secret"
BETTER_AUTH_URL="http://localhost:3000"

# Transactional Email (Resend)
RESEND_API_KEY="re_your_api_key"

# Vercel Blob (Asset uploads)
BLOB_READ_WRITE_TOKEN="vercel_blob_token"

# Gemini AI Assistant
GEMINI_API_KEY="your-gemini-api-key"
GEMINI_MODEL="gemini-3.5-flash-lite"
```

### 3. Initialize & Seed Database
```bash
# Set up MongoDB collections, validators, and indexes
npm run init-db

# Seed initial product catalog, services, and admin accounts
npm run seed
```

### 4. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
